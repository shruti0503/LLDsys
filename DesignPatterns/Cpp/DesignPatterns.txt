# Strategy design pattern 
-> used when we want to define a family of algorithms or behaviours and make them interchnagle.
this pattern aloows the behavior of a class to be changed at runtime by using different Strategies without
altering the code of the class itself.

EXAMPLE
Imagine you're playing a game, and your character can move in different ways: by walking, running, or swimming. You can switch between these behaviors dynamically depending on where your character is.

Context: The character in the game.
Strategies: Walking, Running, Swimming.
